# Домашнее задание к занятию "`Репликация и масштабирование. Часть 2" - Кобалия Иосиф`

---

### Задание 1

1. Активный Master + пассивный Slave преимущества:
   Отказоустойчивость. Данные постоянно реплицируются. Если Master упадёт, Slave можно сделать новым Master. При этом производительность не увеличивается.
2. Master + несколько Slave преимущества:
   Запросы на чтение распределяются по Слейвам, что снижает нагрузку на Master и благодаря чему можно обслуживать больше пользователей одновременно. При отказе Master один из Slave также можно назначить новым Master.



Первый вариант прежде всего обеспечивает отказоустойчивость, а второй отказоустойчивость и горизонтальное масштабирование чтения.


---

### Задание 2

1. Распределение данных

- Сервер 1 (Master ): хранит таблицу книг с ID до 100 000 включительно.
- Сервер 2 (Master): хранит таблицу книг с ID более 100 000.
- Сервер 3 (Master): хранит таблицы пользователей и магазинов.

Такое распределение позволяет разделить нагрузку между серверами.

2. Режимы работы серверов

Все три основных сервера работают в активном режиме (Master), обслуживая запросы на чтение и запись.

Для каждого основного сервера предусмотрен резервный сервер (Slave), работающий в пассивном режиме. Реплики получают изменения с основных серверов, но в обычных условиях не обслуживают запросы приложения.

3. Маршрутизация запросов

Приложение обращается к маршрутизатору, который определяет нужный сервер по типу запрашиваемых данных. Для книг по ID записи.
